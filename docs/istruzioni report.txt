Il report per il progetto di Computational Intelligence deve essere un **file PDF privato** inviato via email sia al professore che al collaboratore. Non è necessario che il report segua un formato preciso, ma deve includere una descrizione delle idee alla base del programma. Il report deve essere una **relazione informale** sull'attività svolta durante l'anno, includendo laboratori, recensioni e lavoro di progetto.

Ecco i dettagli principali che il report deve contenere:

*   **Descrizione del progetto:** Il report deve includere una descrizione delle idee alla base del programma e delle funzioni sviluppate per il progetto di regressione simbolica.
*   **Codice sorgente:** Il report deve contenere tutto il codice sorgente necessario. È possibile utilizzare Markdown per strutturare il testo e includere il codice.
*   **Dettagli del lavoro di gruppo:** Se si è lavorato in gruppo, il report deve indicare i contributi di ciascun membro. È importante che ogni membro del gruppo sia consapevole di ogni singola linea di codice e che, in caso di collaborazione, sia chiaramente indicato nel report.
*   **Dichiarazione di utilizzo di codice di terzi:** Nel caso in cui si sia utilizzato codice di terzi, è fondamentale dichiararlo apertamente nel report, specificando la fonte e il grado di comprensione di tale codice. In caso contrario si rischia di dover rifare il progetto.
*   **Giustificazione delle scelte:** Nel caso in cui si facciano assunzioni, come la similarità tra dati di training e test, è importante specificarlo chiaramente, valutando pro e contro di tali ipotesi.
*  **Discussione delle proprie scelte:** Il report deve includere una discussione delle proprie scelte e di come si è sviluppata la soluzione al problema.

**Formato del report:**

*   Il report è un file PDF privato.
*   Deve essere autonomo e non dipendere da link esterni.
*   Si consiglia di usare Markdown per la formattazione.
*   Non c'è una dimensione specifica, non bisogna preoccuparsi della lunghezza.
*   Il report è informale.

**Contenuto del report:**

*   Il report deve contenere una descrizione dell'attività durante l'anno, includendo laboratori, recensioni e lavoro di progetto.
*   Deve contenere la motivazione per ogni soluzione sviluppata, inclusa una spiegazione dettagliata del codice utilizzato.
*   Se si è lavorato in gruppo, il report deve contenere l'opinione personale sul lavoro di gruppo.

**Importante:**

*   Il report è fondamentale per la valutazione del progetto. Le idee descritte nel report sono ciò su cui si baserà la valutazione del progetto e non il formato del report stesso.
*   Ogni studente deve presentare un proprio report e un proprio file di codice (`s[ID_STUDENTE].py`).
*   Il codice deve essere realizzato individualmente e la similitudine di codice non dichiarata può portare a penalizzazioni.
*   Il report deve essere consegnato una settimana prima dell'esame.

**Scopo del report:**

*   Verificare che lo studente sia l'autore del codice presentato.
*   Permettere ai docenti di comprendere le scelte progettuali dello studente.

In sintesi, il report deve essere una documentazione chiara e completa del lavoro svolto, evidenziando il processo di sviluppo, le scelte progettuali e la comprensione del codice.
