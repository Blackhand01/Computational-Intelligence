🎉 Great job! 🎉

The code you developed for the Simulated Annealing and Random Mutation Hill Climbing algorithms is really well done! The structure is clear, and the functions are well-defined, making it easy to understand and modify.

The implementation of advanced heuristics making the search significantly more efficient. The improved_manhattan function, in particular, is a brilliant idea: it enables the combination of multiple heuristics with customizable weights, providing an elegant and flexible solution, perfect for tackling puzzles of varying sizes.

Here are a few suggestions to make it even better:

Docstrings: adding docstrings to document functions and classes would help clarify their purpose and functionality.
Graphs: including a brief explanation in the README or annotations directly on the graphs would make it easier to understand what they represent and how to interpret them, enhancing their utility and accessibility.
PriorityQueue Performance:
the current implementation uses the sort function to reorder the queue with each insertion, which may slow down performance on larger datasets. Switching to a heap-based structure would improve efficiency.
Overall, this code is outstanding and shows great attention to detail. Truly, congratulations on a job well done! 🎉
